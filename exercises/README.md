**How to get the most from them**
- Try before you look. Ten minutes stuck teaches more than ten minutes reading an answer.
- For the written ones, actually write. For the interview ones, say them out loud.
- A model answer is one good answer. If yours is different and you can explain why, it counts.
- Every code answer here was run for real. If you get a different output from an AI exercise, that's normal: models don't answer the same way twice. Check the meaning, not the wording.
